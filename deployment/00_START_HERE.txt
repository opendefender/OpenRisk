⚠️ IMPORTANT NOTES
═══════════════════════════════════════════════════════════════════════════

1. Render Sleep Mode
   ├─ Free tier services sleep after 15 min of no requests
   ├─ They wake up in 30-60 seconds when called
   ├─ Use uptimerobot.com (free) to keep always alive
   └─ Ping: https://openrisk-api.onrender.com/api/health every 14 min

2. Storage Limits
   ├─ Supabase: 500 MB (archive old data when nearing limit)
   ├─ Redis: 30 MB (implement session cleanup)
   └─ Vercel: 100 GB/month bandwidth (optimize images)

3. Database & Cache
   ├─ PostgreSQL runs fine on 500 MB for demos
   ├─ Redis 30 MB enough for session storage
   ├─ Monitor usage in service dashboards
   └─ Upgrade when hitting limits

4. GitHub Repository
   ├─ All code is public (free tier)
   ├─ That's fine for open-source projects
   ├─ Private repos available on paid plans
   └─ No security risk if properly configured
